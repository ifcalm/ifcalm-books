## 目录约定

- 经部、子部、道家采用“大类 → 书籍 → 篇卷”。
- 佛学采用“佛学 → 部类 → 书籍 → 卷”，不再按经藏、论藏或经典系另设层级。
- 单篇、单卷书籍直接使用 Markdown 文件；多篇、多卷书籍使用目录，并以 `_index.md` 提供书目页。
- 同一书的正文直接放在书籍目录中，通过 `weight` 排序，不再建立上经、下经或卷号范围子目录。
- 顶层保留经部、佛学、道家、子部这些现有入口；目录统计包含草稿，发布状态由 `draft` 控制。
